# Проект для «Викишоп»

**Описание проекта**

Интернет-магазин «Викишоп» запускает новый сервис. Теперь пользователи могут редактировать и дополнять описания товаров, как в вики-сообществах. То есть, клиенты предлагают свои правки и комментируют изменения других. Магазину нужен инструмент, который будет искать токсичные комментарии и отправлять их на модерацию. 


**Цель**

Реализовать модель для классификации комментариев к описанию товаров на позитивные и негативные. 


**План реализации**

1. Загрузка и анализ данных.
2. Подготовка данных.
3. Обучение моделей и поиск лучшей. 
4. Проверка качества классификации комментариев на тестовой выборке.
5. Формулирование выводов.


**Результат и критерий успеха**

- В результате у нас должна получиться обученная модель, способная классифицировать комментарии к описанию товаров интернет-магазина «Викишоп» на позитивные и негативные
- Значение метрики качества `F1` на тестовой выборке должно быть не меньше `0.75`

Для выполнения проекта применять *BERT* необязательно, но мы можем попробовать.


**Описание данных**

В вашем распоряжении набор данных с разметкой о токсичности правок.

Данные находятся в файле `toxic_comments.csv`: 
- Столбец `text` содержит текст комментария, 
- `toxic` — целевой признак (`0` - нетоксичный, `1` - токсичный).

___
В данном проекте мы разработали и обучили модель `LogisticRegression`, способную классифицировать комментарии к описанию товаров интернет-магазина «Викишоп» на позитивные и негативные.
- Параметры пайплайна: `{'preprocessor__tfidf__ngram_range': (1, 2), 'model__solver': 'liblinear', 'model__penalty': 'l2', 'model__C': 10.0}`
- По результатам тестирования модель показала результат (`F1-score = 0.790`), удовлетворяющий требованию заказчика (`F1-score` не менее `0.75`)

___
В рамках решения указанной задачи были выполненны следующие этапы:

**1. Загрузка и анализ данных**

- Выполнили загрузку предоставленного набора данных с разметкой о токсичности правок в датафрейм `df_toxic_comments`. 
- Основные особенности данных:
    - доступно 159292 записи, содержащей текст комментария на английском языке и целевой признак отношения его к классу `1`- токсичен / `0` - не токсичен
    - наблюдается сильный дисбаланс классов целевого признака (`1`- 10% | `0` - 90%)
    - дубликатов и пропусков нет
    - дополнительно можно заметить, что 158 строк возможно были удалены из предоставленного набора данных (т.к. максимальный индекс строки = 159450)


**2. Подготовка данных**

- Выполнили шаги по предобработке текста:
    - удалили все символы, кроме букв и пробелов, 
    - привели к нижнему регистру,
    - разбили текст на отдельные токены,
    - привели слова к базовой форме (лемматизировали),
    - удалили стоп-слова и сохранили только буквенные токены,
    - удалили 108 строк из датафрейма, содержащие пустые тексты после обработки
- Выполнили разделение данных на обучающую и тестовую выборки в соотношении в соотношении 75%/25%
- Подготовили Pipeline, включающий векторизацию текста с помощью `TfidfVectorizer` и модель
- Выполнили взвешивание классов - токсичные комментарии получают больший вес при обучении. Веса классов: `{0: 0.5565874125874126, 1: 4.917943648047454}`


**3. Обучение моделей и подбор гиперпараметров**

Выполнили обучение моделей и получили следующие результаты по качеству предсказаний на кросс-валидации:
- 1 место `LogisticRegression`, где `F1-score` = 0.778 
- 2 место `CatBoostClassifier`, `F1-score` = 0.716
- 3 место `RandomForestClassifier`, `F1-score` = 0.495  

В качестве лучшей выбрали `LogisticRegression {'preprocessor__tfidf__ngram_range': (1, 2), 'model__solver': 'liblinear', 'model__penalty': 'l2', 'model__C': 10.0}`


**4. Тестирование лучшей модели**

По результатам тестирования модель `LogisticRegression` показала результат (`F1-score= 0.790`), удовлетворяющий требование заказчика (`F1-score` не менее `0.75`)
